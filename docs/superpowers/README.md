# Historical planning records

The spec and plan in this directory are point-in-time records from the
2026-08-17 build-tooling migration, kept for provenance. They describe the
design as it stood before implementation: embedded code snippets, task
checklists and workflow directives have not been updated since and several
details (the version-stamp regex, verify checks, link-check classification)
have been superseded by the implemented code under `tools/drdebits_build/`.
The code and its tests are authoritative; do not implement from these files.
