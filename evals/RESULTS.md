# DrDebits evaluation results

Part of [DrDebits](../drdebits.md) `0.5.0`. Generated by the build from `evals/results/*.json`; edit those files, never this table. Each run column is one manual evaluation: the model, the guide version it ran against (with the guide commit where the run recorded one), the date, and a verdict per behaviour test: `pass`, `fail`, `violation` where the case rubric was met but the whole response broke another guide control, or `n/a` where the run did not cover a case. Only `pass` counts as passed. Where a run took more than one sample per case, a cell counts each sample's verdicts, a case passes only when every sample passed (all-of-k), and the total adds the share of samples that passed (pass@1). Records in this section are human-confirmed; legacy records predate the explicit `verdict_basis` field. Proposed verdicts live in `evals/observations/` and are shown in their own section below, never added to a confirmed pass count. No prompts, outputs or transcripts are recorded here or anywhere in this repository.

**Current-revision confirmed coverage: 0/100 cases.** Coverage records assessment, not a pass or deployment approval. Runs with different models or conditions remain separate.
